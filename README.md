# KALOP · Control de ingreso

Pantallas de control de ingreso por DNI para el evento de KALOP.

- `invitados.html`: clientes invitados (franja celeste).
- `personal.html`: Personal y Externos, entrada y salida (franja naranja).

Las listas y los registros viven en una Planilla de Google privada; estas páginas
solo los consultan con el PIN de cada sistema. El código no contiene datos de personas.
